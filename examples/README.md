# Examples

Sketches showing how to wire the library. They are not published to npm.

- [`node-api/example.ts`](./node-api/example.ts) — Node / route-handler style with `createCircuitFetch`
- [`nextjs/example.tsx`](./nextjs/example.tsx) — `CircuitProvider` + `useCircuitBreaker`

Install the package (or link the workspace build) before running these snippets in an app.
